# Титаник: цена билета и выживаемость

Учебный проект по анализу данных (НИУ ВШЭ). Датасет: Kaggle (tested.csv, пассажиры Титаника).

## Вопросы
1. Как распределена цена билета внутри классов?
2. Связана ли цена билета с выживанием?
3. Различается ли средняя цена у выживших и погибших (t-тест)?
4. Как семейный статус связан с ценой и выживаемостью?

## Результаты
- В 1-м классе огромный разброс цен (£26–512), во 2-м и 3-м цены однородные
- Выжившие в среднем платили больше (£49 против £28), p < 0,05
- Выживаемость растёт с квинтилем цены: ~30% в самом дешёвом, ~52% в самом дорогом
- Одиночки выживали реже (27%), чем пассажиры с семьёй

## Ограничения
Цена связана с классом и полом, поэтому разница в выживании может объясняться ими,
а не самой ценой. Это корреляция, а не причинность.
